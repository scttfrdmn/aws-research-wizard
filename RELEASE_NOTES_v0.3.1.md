## 🚀 **Getting Started**

### **Installation (Choose One)**
```bash
# macOS/Linux via Homebrew
brew install aws-research-wizard

# Windows via Chocolatey
choco install aws-research-wizard

# Any platform via Conda
conda install -c conda-forge aws-research-wizard
```

### **First Steps**
```bash
# Configure AWS credentials
aws configure

# See available research domains
aws-research-wizard config list

# Deploy a genomics environment
aws-research-wizard deploy --domain genomics --region us-west-2
```
